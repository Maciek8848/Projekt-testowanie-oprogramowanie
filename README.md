# Projekt-testowanie-oprogramowanie
Projekt na tesowanie oprogramowania - "Recenzja prac naukowych"

Testy operacji Create, Read, Update, Delete (CRUD) dotyczących wybranej bazy danych przechowującej dowolne dane.

Język programowania i IDE -- do wyboru.

Przykładowe narzędzia -- JUnit, TestNG, AssertJ.

Wymagania i punktacja:

1.) Aplikacja implementująca operacje Create, Read, Update, Delete (CRUD) (5 punktów).

2.) Baza danych (5 punktów).

3.) Testy operacji (CRUD) (10 punktów).

Uwaga: w przypadku oddania projektu po upływie wyznaczonego terminu, można otrzymać maksymalnie 11 punktów.


strony naszej aplikacji:
1. logowanie użytkownika
2. lista wszystkich prac (z recenzją jeżeli jest)
3. dodaj swoją pracę
4. edytuj pracę
5. zobacz jakąś pracę
6. recenzuj czytaną pracę
